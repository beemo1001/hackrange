# HackRange · The Practice Arena

A free hacking practice arena for security students. 54 built-in labs that run entirely in the browser, 121 curated external labs, 6 learning paths, XP, ranks and badges. No backend, no account, no telemetry. Deployable on GitHub Pages in one push.

Companion to **BountyFlow** (the bug bounty aggregator) and **SecLab** (the student security field kit).

## What is inside

### The Arena (54 built-in labs, 8 categories)

| Category | Labs | What it practices |
|---|---|---|
| Encoding & Decoding | 7 | base64 chains, hex, double URL encoding, unicode escapes, JWT structure |
| XSS Playground | 8 | simulated reflection contexts with real filter logic to bypass |
| SQL Injection | 8 | mock query console: UNION attacks, WAF space filters, blind, timing, hex-only |
| Command Injection | 6 | blacklists, string obfuscation, wildcards, out of band exfiltration |
| Payload Adaptation | 7 | a payload failed: diagnose why from the evidence, then produce the fix |
| Linux Diagnosis | 6 | an interactive simulated terminal: permissions, disks, nginx, DNS, cron, inodes |
| Assembly Reading | 6 | x86-64 calling conventions, loops, overflow patterns, hidden constants |
| Crypto & Hashes | 6 | hash identification, weak secrets, XOR key reuse, Caesar, JWT none |

Every lab has:
- a mission brief with a story
- an interactive challenge environment (reflection page, SQL console, command shell or Linux terminal)
- a 3 step hint ladder (free) plus a full walkthrough (reveals the why, halves the XP if opened before solving)
- a study note pointing to the matching SecLab section

Static answer labs are validated against SHA-256 hashes of accepted answers: viewing the source does not give you the flags.

### The Directory (121 external labs)

Curated, filterable (category, level, cost, setup) and honest: PortSwigger Academy, OverTheWire, picoCTF, TryHackMe free rooms, HTB, OWASP Juice Shop, DVWA, Root Me, cryptohack, cryptopals, pwn.college, Hacker101 CTF and more. Each entry says what you learn and gives a student tip. Pricing labels were accurate at the time of writing; platforms change their free tiers, so treat them as a guide.

### Learning Paths (6 roadmaps)

Day Zero, Web Exploitation, Bug Bounty Ready, Linux & PrivEsc, Reverse Engineering, CTF Prep. Steps check themselves off automatically as you solve the labs they reference.

### Progress

- XP: Easy 10, Medium 25, Hard 50, Insane 100. External labs 5 each.
- Ranks: Script Kiddie, Junior Pentester, Bug Hunter, Security Researcher, Elite Hacker.
- 10 badges: First Blood, Warming Up, Double Digits, Halfway There, Completionist, Purist, Category Master, Explorer, Cartographer, Night Owl.
- Progress lives in localStorage. Export and import as JSON. Reset anytime.
- Opening the full walkthrough before solving halves that lab's XP. Hints 1 to 3 are free.

## Deploy on GitHub Pages

1. Create a new repository (or a subfolder of an existing one).
2. Copy everything in this folder into it: index.html, css/, js/, logo.svg, robots.txt, .nojekyll.
3. Push. Settings > Pages > Deploy from branch > main / root. Done.

Everything uses relative paths, so it works at the repo root or under a subpath. The .nojekyll file tells GitHub Pages to serve the js folder as-is.

## Run locally

Open index.html directly in a browser, or:

```
cd hackrange
python3 -m http.server 8000
```

Then visit http://localhost:8000. Works fully offline (Google Fonts fall back to the system stack when unreachable).

## Ethical use

Every target in HackRange is either simulated in your browser or a platform that exists for legal practice. The skills transfer to real bug bounty programs, where scope rules and authorized testing are the difference between a researcher and a criminal. Stay in scope. Always.

## Rebuilding materials

Flag hashes and encoded challenge strings are generated by `scripts/gen_materials.py` (kept outside this folder). If you fork this project and want your own flags, edit that script and regenerate `js/lab-materials.js`. The offline test suite `scripts/test-hackrange.js` verifies every hash, every encoding round trip and the engine logic.

Free forever. No APIs, no keys, no telemetry. Progress never leaves the browser.
